# Data Science Learning

A collection of coursework, practical assignments, and experiments for **Advanced Data Science Lab (MCA33PE21)**.

## Repository layout

| Directory | Contents |
| --- | --- |
| [`Assignment 1`](Assignment%201) | Python environment setup, core programming/statistics, and Pandas/NumPy/visualization exercises. |
| [`Assignment 2`](Assignment%202) | NumPy, Pandas, Matplotlib, Seaborn, and scikit-learn work, with Streamlit dashboard experiments. |
| [`Assignment 3`](Assignment%203) | Data preprocessing, feature engineering, and exploratory data analysis. |
| [`Example`](Example) | A simple linear-regression example and its sample data. |

## Highlights

- Data manipulation and analysis with Pandas and NumPy
- Visualizations with Matplotlib and Seaborn
- Introductory machine-learning workflows with scikit-learn
- Interactive Streamlit dashboards for retail sales, student grades, movie ratings, and Titanic survival analysis
- Data cleaning, feature engineering, and exploratory data analysis

## Getting started

Create and activate a Python virtual environment, then install the dependencies:

```bash
pip install -r requirements.txt
```

Open the notebooks with Jupyter:

```bash
jupyter notebook
```

For an interactive dashboard, run its matching application from `Assignment 2/Experimential/EL2`:

```bash
streamlit run app1.py
```

The CSV files used by each assignment are stored alongside the corresponding notebook or application.

## Notes

This repository contains academic learning material and sample datasets. The local virtual environment and personal development-machine files are intentionally excluded from version control.
